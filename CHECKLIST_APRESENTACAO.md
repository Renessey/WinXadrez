# Checklist de apresentacao - WinXadrez

## Antes da gravacao

- [ ] Executar `npm ci` se as dependencias ainda nao estiverem instaladas;
- [ ] Executar `npm run typecheck`;
- [ ] Executar `npm run test:sqlite`;
- [ ] Iniciar o aplicativo por `npm start` ou `npm run android`;
- [ ] Confirmar que a tela abre sem erros visiveis;
- [ ] Confirmar que um perfil de teste ja existe;
- [ ] Preparar uma partida curta para demonstrar movimentos;
- [ ] Separar a tela inicial, o ranking e o perfil para transicoes rapidas;
- [ ] Garantir energia da bateria e desativar notificacoes;
- [ ] Confirmar conexao com a internet caso o puzzle Lichess sera usado.

## Sequencia da gravacao

- [ ] Apresentar o nome e o objetivo do projeto;
- [ ] Mostrar a abertura do aplicativo;
- [ ] Criar ou mostrar o perfil;
- [ ] Iniciar uma partida contra o bot;
- [ ] Escolher dificuldade e fazer pelo menos dois lances;
- [ ] Mostrar a troca de turno ou o modo contra amigo;
- [ ] Navegar por puzzles e tutorial;
- [ ] Mostrar ranking, niveis e perfil;
- [ ] Explicar as tabelas do banco `winxadrez.db`;
- [ ] Mostrar ou explicar o resultado de `npm run test:sqlite`;
- [ ] Encerrar com um resumo em ate cinco minutos.

## Alternativas para falhas

- [ ] Se o Lichess estiver indisponivel, usar os puzzles offline;
- [ ] Se o perfil nao estiver criado, realizar o onboarding rapidamente;
- [ ] Se a partida estiver salva, usar continuar ou reiniciar;
- [ ] Se houver erro no terminal, usar o teste SQLite ja preparado como evidencia;
- [ ] Evitar abrir telas desnecessarias durante a gravacao.

## Apos a gravacao

- [ ] Conferir que o audio esta audivel;
- [ ] Conferir que o tabuleiro e os botoes aparecem na tela;
- [ ] Conferir que a duracao total nao ultrapassa cinco minutos;
- [ ] Confirmar que a explicacao do SQLite foi compreendida;
- [ ] Exportar ou publicar o video no destino solicitado pelo trabalho.
